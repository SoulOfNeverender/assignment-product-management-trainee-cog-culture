# Submission Checklist

## Before submission

- [ ] Create/paste Gemini and Tavily keys in Streamlit Community Cloud secrets.
- [ ] Deploy the app and open it on a mobile and desktop browser.
- [ ] Upload the trap PDF and a second PDF to verify the sample and error states.
- [ ] Push the final repository to GitHub.
- [ ] Record a 30-second demo.
- [ ] Export the PPT/PDF and verify all 13 slides open correctly.

## 30-second demo script

“This is Truth Layer, a fact-checking agent for PDF reports. I upload the brief, it extracts the
most checkable claims, searches live web evidence in parallel, and assigns a verdict with a
source and confidence. Here is an outdated Netflix subscriber claim, marked Inaccurate with the
latest reported figure. Here is a fabricated claim, marked False. You can filter verdicts and
download the full JSON or CSV evidence report.”
